# ZERO HOUR 2.0 — CORE LOOP REDESIGN

## 1. 핵심 플레이 공식

ZERO HOUR의 핵심 플레이는 다음 순환이다.

경험 → 이상 징후 → 판단 → 행동 → 실패 또는 기회 상실 → 정보 획득 → 루프 → 미래 예측 → 개입 → 사건 변화 → 새로운 결과 → 더 큰 의문

이 가운데 **미래 예측 → 개입 → 사건 변화**가 핵심 재미다. 기억은 읽는 수집품이 아니라 과거의 행동을 바꾸는 도구다.

Loop 2가 Loop 1과 같은 장면을 다른 색의 대사로 반복한다면 실패다. 미래를 안다는 사실이 시간, 공간, 위험, NPC 행동, 정보 중 하나 이상을 실제로 바꿔야 한다.

## 2. Knowledge Reward Rule

모든 중요한 Memory에는 Gameplay Payoff가 있어야 한다. 콘텐츠를 작성할 때 다음 항목을 함께 정의한다.

- **예측 사건:** 어떤 미래 사건을 아는가?
- **사용 시점:** 언제 개입할 수 있는가?
- **변화:** 무엇이 달라지는가?
- **절약 시간:** 반복이나 시행착오를 몇 분 줄이는가?
- **회피 위험:** 어떤 실패·사망·제지를 피하는가?
- **해금 경로:** 어떤 선택이나 장소가 새로 열리는가?

한 기억이 모든 항목을 채울 필요는 없다. 다만 중요한 기억은 아래 보상 중 최소 하나를 실제 state 변화로 제공해야 한다.

- 시간 절약
- 위험 회피
- 새로운 장소 또는 선택
- 사건 선점
- NPC 행동 변화
- 이전에는 불가능했던 정보 결합

본문에서 사용할 수 없는 설정 설명만 주는 기억은 핵심 보상으로 취급하지 않는다.

## 3. 반복 대화 압축

반복 대화 압축은 Skip 버튼이 아니다. 이미 아는 결론을 근거로 주인공이 질문 순서를 바꾸고, 상대가 하려던 말을 선점하는 세계관 내부 행동이다.

규칙:

1. 첫 경험에서는 전체 대화와 시간 비용을 치른다.
2. 기억을 보유한 다음 루프에는 Foreknowledge 선택이 열린다.
3. 선택하면 요약된 새 장면으로 이동하고 실제 시간이 줄어든다.
4. 절약된 시간으로만 가능한 후속 행동을 최소 하나 제공한다.
5. 압축 장면은 원문을 다시 요약해 읽게 하지 않고, 달라진 주인공과 NPC 반응을 보여준다.

첫 구현에서는 유진과의 10분 대화를 1분으로 줄여 9분을 확보한다.

## 4. 첫 번째 Knowledge Payoff

### Loop 1 경험

00:00 정전 순간 1층 뒤편 서비스 출입문의 전자 잠금이 잠깐 해제된다. 처음에는 위치를 선점하지 못해 문을 이용하지 못하고, 로비의 경비 대응으로 사망한다.

획득 기억은 두 사실을 함께 보존한다.

- 정전은 00:00에 발생한다.
- 정전 순간 1층 서비스 출입문의 잠금이 해제된다.

### Loop 2 개입

1. 유진 반복 대화를 1분으로 압축한다.
2. 확보한 시간에 서비스 출입문 위치를 미리 확인한다.
3. 23:55에 문 앞으로 간다.
4. 00:00의 잠금 해제를 기다린다.
5. 로비 사망 위험을 피하고 `B1_SERVICE_CORRIDOR`에 진입한다.

이 변화는 대사 차이가 아니라 시간, 위치, 장면, 위험, 획득 단서를 모두 바꾼다.

## 5. 첫 번째 새 경로

`B1_SERVICE_CORRIDOR`는 Vertical Slice 검증용 최소 공간이다. B1 전체 콘텐츠를 의미하지 않는다.

- Loop 1: 잠금 해제를 멀리서 듣고 접근 기회를 놓친다.
- Loop 2: 정전 전에 문을 선점해 진입한다.
- 보상: `CLUE_SERVICE_CORRIDOR_LOG`
- 발견: 21:58에 C.M.S. 명의로 B1 전실 승인이 기록되어 있다.
- 남는 의문: 서윤의 예약 메시지 시각과 전실 승인 시각이 왜 같은가?

게임 본문은 이 관계를 정답처럼 해설하지 않는다.

## 6. 분기와 합류

분기는 다시 합류할 수 있다. 다만 합류 전에 다음 중 하나 이상이 state에 남아야 한다.

- 다른 단서나 기억
- 다른 현재 시간
- 다른 위치
- NPC 플래그 변화
- 다른 위험 노출
- 다른 후속 선택

문장만 달랐고 state와 후속 행동이 같다면 의미 있는 분기로 보지 않는다.

## 7. 주인공 행동 원칙

확인한다. 의심한다. 시험한다. 우회한다. 실패하면 기억한다. 다음에는 먼저 움직인다.

NPC의 지시는 선택 가능한 상황이다. 주인공은 이유 없이 따르지 않지만 문을 부수거나 사람을 공격해 문제를 해결하지도 않는다. 지식과 타이밍으로 우회한다.

## 8. Vertical Slice 성공 기준

Loop 1과 Loop 2를 연속 플레이했을 때 Loop 2에서 다음을 직접 체험해야 한다.

- 반복 대화 하나 압축
- 미래 사건 하나 선점
- 위험 하나 회피
- 새로운 장소 하나 진입

네 항목이 모두 실제 선택과 state 변화로 확인되어야 한다.

## 9. 구현 경계

현재 엔진에는 Memory의 Gameplay Payoff 메타데이터만 선택적으로 추가한다. 실행은 기존 조건과 효과 조합으로 표현한다.

- `hasMemory`: Foreknowledge 해금
- `advanceTime`: 반복 압축과 준비 시간
- `moveLocation`: 선점 위치 및 새 경로
- `jumpScene`: 사건 변화
- `gainClue`: 새 경로 보상
- `setFlag`: 압축·준비·개입 상태

이번 단계에서는 범용 이벤트 스케줄러, Zustand, 저장, B1 전체 콘텐츠를 추가하지 않는다.
