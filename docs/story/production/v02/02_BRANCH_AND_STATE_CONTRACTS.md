# ZERO HOUR — BRANCH AND STATE CONTRACTS v02

## 1. 분기 원칙

1. 선택은 즉시 같은 문장으로 지워지지 않는다.
2. 재합류 전에는 반드시 시간, 정보, 위험, 관계, 소지품 중 하나가 달라진다.
3. 플레이어가 보지 못한 장면의 정보를 주인공이 아는 것처럼 말하지 않는다.
4. 필수 정보는 서로 다른 두 경로로 얻을 수 있다. 한 번의 선택 실수로 본편이 막히지 않는다.
5. 진엔딩은 모든 선택의 정답을 요구하지 않는다. 독립된 세 사람의 신뢰와 세 개의 물리 기준점이면 도달할 수 있다.
6. 분기 재합류 대사는 공통 사실만 사용하고, 차이는 짧은 조건 대사로 먼저 회수한다.

## 2. 핵심 영속 상태

`TRUST_*`는 NPC가 루프를 넘어 감정 상태를 그대로 기억한다는 뜻이 아니다. 플레이어가 그 인물에게 무엇을 어떤 순서로 증명해야 하는지 알아냈다는 영속 지식이다. 새 루프에서는 해당 증명 장면을 짧은 기억 행동으로 다시 수행해야 협조 상태가 열린다.

| 상태 | 획득 | 이후 변화 |
|---|---|---|
| `MEMORY_0106_SEAL` | Loop 2 두 번째 죽음 | 01:06 밀폐 회피, B2 우회 계단 선점 |
| `KNOWS_FAILED_NIGHTS_CONTINUE` | CH5 로그 재생 | CH6에서 과거 인스턴스 개입 가능 |
| `KNOWS_ANCHOR_2123` | 민서 기록 + 외부 기준 로그 | 최종 루프에서 연결 대상 판별 |
| `TRUST_YUJIN` | 환자 안전 증거를 먼저 보여 줌 | 수동 산소 밸브, 입실 라벨, 대피 협조 |
| `TRUST_TAEJUN` | 위험을 예측해 다른 사람을 보호함 | CCTV 원본, B2 열쇠, 보안 방송 |
| `TRUST_SEA` | 틀린 기억을 비난하지 않고 검증함 | 겹친 인물 구분, 감정 오염 안정화 |
| `TRUST_MINSEO` | 기억 일부를 검증 가능한 형태로 공개 | 차폐실 기록, 장치 조작 협조 |
| `MINSEO_FULL_DISCLOSURE` | 모든 죽음 기억을 민서에게 공개 | 빠른 설명, 대신 마지막 통제권 충돌 |
| `BAND_CUSTODY_*` | CH3 손목밴드 선택 | CH4 증거 접근 경로 변화 |
| `RESCUED_LEFT_BEHIND_*` | CH6 과거 밤 개입 | 최종 구조 인원과 진엔딩 보조 조건 |

## 3. 손목밴드 보관 분기

### 유진에게 사진을 남기고 돌려준다

- `TRUST_YUJIN +1`
- 유진이 병원 봉인 봉투에 넣고 라벨 재출력 기록을 확보한다.
- CH4에서 원본을 다시 보려면 유진의 협조가 필요하다.

### 태준에게 확인시킨 뒤 돌려받는다

- `TRUST_TAEJUN +1`
- 보안 카메라로 원본 소지 시각이 남는다.
- CH4에서 주인공이 조작했다는 의심을 피할 수 있다.

### 사진만 남기고 계속 보관한다

- `TRUST_YUJIN -1`
- B1 이송실에서 직접 대조할 수 있다.
- 두 번째 죽음 뒤 원본은 해당 인스턴스에 남고, 다음 루프에는 사진 기억만 남는다.

세 경로 모두 `06이 같은 관찰 세션을 가리킨다`는 결론에 도달한다. 증거를 누가 신뢰하는지만 달라진다.

## 4. CH4 신뢰 경로

플레이어는 한 루프에서 주 경로 하나와 보조 경로 하나를 선택한다.

| 주 경로 | 필수 행동 | 얻는 것 | 놓치는 것 |
|---|---|---|---|
| 유진 | 중복 라벨과 산소 기록 대조 | B2 수동 밸브, 서윤 입실 인정 | CCTV 원본 전체 |
| 태준 | 01:06 사고 선제 방지 | B2 열쇠, CCTV 시간 오차 | 약품 투여 세부 |
| 세아 | 세아 기억을 물리 단서 두 개로 검증 | 손잡이가 바뀌는 문 규칙 | 직원의 공식 협조 |

보조 경로는 핵심 단서 하나만 준다. 선택하지 않은 인물이 이후 장면에서 갑자기 모든 내용을 공유하지 않는다.

## 5. CH5 관찰실 선택

### 서윤의 목소리를 따라간다

- `SEYUN_INSTANCE_MARK` 획득.
- 현재 통화 중인 서윤의 위치를 좁힌다.
- 세아의 오염이 악화되어 CH6 초반 안정화 장면이 추가된다.

### 세아를 먼저 안정시킨다

- `TRUST_SEA +1`, `SEA_GESTURE_KEY` 획득.
- 서윤 위치 단서는 늦게 얻어 다음 장의 시간이 8분 줄어든다.

### 장치 로그를 확보한다

- `FAILED_NIGHT_LOG_COMPLETE` 획득.
- 떠난 밤의 생존자 수를 정확히 안다.
- 서윤과 세아 모두 관계 점수가 오르지 않는다.

세 경로 모두 `떠난 밤이 계속된다`는 사실을 알지만, 감정 장면과 최종 구조 난도가 달라진다.

## 6. CH6 과거 인스턴스 개입

한 번의 안정된 송신만 가능하다.

### Loop 1 태준에게 보낸다

- 첫 죽음 뒤 계단 아래로 내려가려는 태준을 멈춘다.
- 태준이 환자 두 명을 지상으로 대피시킨다.
- 최종 루프에서 `보안 방송 우회 코드`가 돌아온다.

### Loop 2 유진에게 보낸다

- 01:06 이송실의 자동 밀폐를 해제한다.
- 유진이 그 인스턴스의 주인공을 발견하지는 못하지만 06 카드 원본을 보존한다.
- 최종 루프에서 `06 원본 체크섬`이 돌아온다.

### 다른 서윤에게 보낸다

- 관찰실 문을 닫지 않게 해 한 인스턴스의 서윤이 B2 복도로 나온다.
- 최종 루프에서 `서윤의 세 번째 현재 사실`이 돌아온다.

어느 선택도 나머지 밤을 무가치하게 만들지 않는다. 진엔딩에는 세 보상 중 하나와 신뢰 인물 세 명이 필요하다.

## 7. 민서 공개 분기

### 기억을 전부 공개한다

- 민서의 설명과 B3 접근이 빨라진다.
- 민서는 주인공을 다시 외부 기준 신호로 고정하려 한다.
- 마지막에 `통제권을 넘긴다 / 직접 순서를 정한다` 갈등이 발생한다.

### 검증된 기억만 공개한다

- 진행은 느리지만 민서가 주인공을 자료가 아닌 협상 상대자로 대한다.
- 최종 루프에서 민서가 장치 정지 권한을 자발적으로 넘긴다.

### 거의 숨긴다

- 태준 또는 유진의 신뢰가 높아야 B3에 진입할 수 있다.
- 민서는 최종 루프 초반까지 적대적이지 않지만 비협조적이다.
- 원본 확인 절차가 한 단계 추가된다.

## 8. 엔딩 조건

### WHITE MORNING

조건:

- 현재 서윤 위치 확인.
- B2 비상 출구 확보.
- 자정 이후 `현재 연결만 안정화한다` 선택.

결과:

- 주인공과 현재 서윤은 병원 밖으로 나온다.
- 새 인스턴스 생성은 멈춘다.
- 다른 밤과의 구조 채널은 닫힌다.

### ONE MORE TIME

조건:

- 최종 선택에서 `다른 밤의 요청을 받는다` 선택.
- 기준점이나 신뢰 인물이 부족해 다중 구조를 안정화하지 못함.

결과:

- 오후 9시 23분으로 새 연결이 열린다.
- 확보한 핵심 기억 하나를 선택해 유지한다.

### ZERO HOUR

필수 조건:

- `KNOWS_FAILED_NIGHTS_CONTINUE`
- `KNOWS_ANCHOR_2123`
- 유진, 태준, 세아, 민서 중 신뢰 3명 이상
- 물리 기준점 3개: 깨진 시계, 06 원본 또는 체크섬, 오래된 안내도/문 위치
- CH6 과거 밤 개입 보상 하나 이상
- 최종 순서 퍼즐 성공

결과:

- 새 인스턴스 생성을 중단한다.
- 열린 구조 채널의 생존자를 현재 병원 동선으로 유도한다.
- 주인공은 원본 판정 로그를 열지 않는다.
- 각 인스턴스에서 돌아오지 못한 사람의 이름과 마지막 행동을 보존한다.

## 9. 재합류 문장 계약

조건 대사는 공통 장면의 첫 문단에서만 갈라지고, 이후 공통 사실로 합류한다.

예:

- 유진 신뢰 있음: `유진은 내가 묻기 전에 봉인 봉투를 꺼냈다.`
- 태준 신뢰 있음: `태준은 보안실 문을 완전히 닫지 않았다.`
- 신뢰 없음: `둘 다 내가 가까이 가자 말을 멈췄다.`

그다음 공통 대사:

> “01시 06분에 B1 이송실이 닫힙니다.”

주인공은 자신이 경험한 사실만 말한다. 보지 않은 분기에서 얻은 세부 이유를 덧붙이지 않는다.
