## 4. 상태 모델 요구사항

영속과 루프 내부 상태를 분리한다.

### 영속

- 죽음으로 얻은 기억.
- 검증을 마친 추론.
- NPC 신뢰를 얻는 증명 순서.
- 과거 인스턴스 개입 결과.
- 도감·밤의 기록.

### 루프 내부

- 현재 시각.
- NPC의 이번 루프 신뢰와 위치.
- 손목밴드·카드·휴대전화의 현재 소유자.
- 문 잠금과 밸브 상태.
- 현재 선택한 서윤 채널.

`TRUST_*` 영속 값 하나로 NPC가 새 루프 시작부터 주인공을 믿게 하지 않는다. 영속 값은 기억 행동을 해금하고, 그 행동을 수행했을 때 이번 루프의 신뢰가 생긴다.

## 5. UI·게임플레이 전달

- 선택지에 내부 상태명이나 정답 색을 노출하지 않는다.
- Foreknowledge는 이미 경험한 사건에만 표시한다.
- 시간 비용은 숫자만 붙이지 않고, 그 시간 때문에 놓치는 사건을 결과로 보여 준다.
- 추론 퍼즐은 단서 2~4개를 직접 연결하게 하되, 오답은 인물 바보 만들기가 아니라 `아직 확정할 수 없음`으로 처리한다.
- 중요한 단서는 대사 중 자동 획득만 하지 않는다. 플레이어가 화면에서 물건이나 문장을 한 번 선택해 확인하게 한다.
- 반복 장면은 기억 행동으로 압축하되, 절약한 시간으로 새 행동을 하게 한다.
- 서윤 A/B/C는 제작용 명칭이다. 화면에는 `A`, `B`, `C`를 인물 이름처럼 표시하지 않는다. 통화 파형, 현재 사실 표식, 마지막 연결 문장으로 구분한다.

## 6. 시각·음향 전달

- 다른 인스턴스는 색상 필터만으로 구분하지 않는다. 물건 위치, 조명 점등 순서, 문 손잡이, 방송 지연을 함께 사용한다.
- 같은 캐릭터를 악한 복제처럼 보이게 하는 표정 연출을 금지한다.
- 공포는 조용한 병원 업무가 어긋나는 순간에서 시작한다.
- CH5 녹음 퍼즐의 세 소리는 실제로 분리해 들을 수 있어야 한다.
- 자정 정전 전후에도 대사와 선택지 가독성을 유지한다.
- 최종 구조 장면은 군중 CG 하나로 대체하지 않는다. 인원 확인, 손잡기, 들것 이동 같은 구체 행동을 보여 준다.
