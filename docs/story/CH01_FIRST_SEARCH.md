# ACT 2–3 — 302호, 자정, 첫 죽음

이 문서는 버티컬 슬라이스의 구현 색인이다. 실제 대사는 `DIALOGUE_SOURCE_PRIORITY.md`에 따라 상세 대화 원문을 우선하고, `ZERO_HOUR_SCENARIO_MASTER_v01.md`는 사건 구조와 확정 상태를 확인할 때 사용한다.

## ACT 2 — 302호의 모순

1. 3층에서 서윤에게 전화하면 302호에서 진동음이 들린다.
2. 302호에서 나온 간호사는 환자가 있다고 말하지만 신원은 공개하지 않는다.
3. 유진은 302호가 비어 있다고 말한다.
4. 방에는 눌린 침구, 새 거즈, 물컵 손자국, 환자용 슬리퍼 등 최근 사용 흔적이 남아 있다.
5. 첫 루프에서는 진동한 휴대전화를 명확히 찾지 못한다.
6. 찢어진 환자 손목밴드에는 302호와 서윤의 생년월일만 남아 있다. 이름은 식별할 수 없다.
7. 서윤은 현장을 볼 수 없는 상태에서 `너 302호에 있었어?`, `그 방에서 내 이름 봤어?`라고 묻는다.

`…06`, `Subject Six`, `Response confirmed`를 이 구간의 확정 단서로 사용하지 않는다.

## ACT 3 — 자정과 첫 죽음

1. 1층 피난 안내도와 복도 끝 직원 외 출입금지 문을 연결한다.
2. 태준은 외부인을 제지하는 보안 담당자로 처음 등장한다.
3. 자정에 병원 전체가 정전된다.
4. 아날로그 시계 초침이 멈추고 직원용 문의 전자 잠금이 풀린다.
5. 첫 죽음은 감각의 파편만 보여 준다. 방법, 정확한 장소, 가해자는 확정하지 않는다.
6. 죽음에서 얻는 정보는 `자정 정전`과 `직원용 문 잠금 해제`다.

## 타이틀 순서

첫 죽음 → 첫 통화 시점으로 복귀 → 깨진 시계가 남은 것을 확인 → 같은 첫 통화 반복 인지 → `ZERO HOUR` 타이틀.

세아의 첫 대사 뒤에 타이틀을 띄우지 않는다.
