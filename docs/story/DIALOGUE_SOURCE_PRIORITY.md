# ZERO HOUR — 대사 기준 우선순위

이 문서는 시나리오 구현 시 어떤 자료를 우선하는지 고정한다.

## 우선순위

1. 사용자의 최신 직접 수정
2. `저장소 확인 요청`에서 장면 번호와 함께 확정한 상세 대화 원문
3. 사용자가 별도로 첨부한 상세 장면 원문
4. `ZERO_HOUR_SCENARIO_MASTER_v01.md`의 사건 구조·확정/보류 상태
5. 연결에 꼭 필요한 최소한의 새 문장

마스터 문서는 전체 구조와 연속성의 기준이지만, 이미 상세하게 깎은 대사를 요약문으로 다시 창작하는 근거로 사용하지 않는다.

## 현재 확인한 상세 원문 계보

- `Opening ACT 0 v0.4` — 남매 통화, 시계, 상반된 문자, 병원 도착
- `Opening ACT 1 v0.2` — 유진 첫 대면, 기록 부정, 직원 반응
- `Opening ACT 2 v0.1` 및 후속 수정 — 302호 진동, 병실 모순, 손목밴드
- `Opening ACT 3 v0.1` — 정전, 첫 죽음, 리셋, 타이틀
- `Loop 2 전반부 v0.2` — 첫 루프 직후의 혼란과 반복 확인
- `Loop 2 중반부 v0.1` — 이른 도착과 첫 번째 휴대전화
- `Loop 2 후반부` — B1, 윤세아, 강태준, 302호 재확인
- `SCENE 4-93` 이후 — 차민서, CCTV, 병원 측의 독립 조사
- `SCENE 4-111~152` — 서윤이가 몰랐던 것, `06`, 오래된 안내도, 서로 다른 302호

## 프로젝트 내 상세 기준본

- `docs/story/LOOP2_SEOYUN_DID_NOT_KNOW.md`는 사용자가 첨부한 `SCENE 4-111~152` 원문을 한 글자도 새로 창작하지 않고 프로젝트 안에 보존한 기준본이다.
- 현재 30~45분 버티컬 슬라이스는 이 기준본 직전에서 끝난다. 후속 구현은 장면을 요약해 한두 개의 새 대사로 대체하지 않고, 이 파일의 장면 번호와 대화를 그대로 데이터화한다.
- `06`, CCTV 1분 공백, 오래된 안내도, 서로 다른 302호는 서로 독립된 확인 단계로 유지한다.

## 금지

- 원문에 없는 성씨, 병실 번호, 코드, 연구명 추가
- 자연스러운 대사를 정보 전달용 문장으로 요약하거나 재작성
- 유진·태준을 초반부터 조사 동료로 취급
- 서윤이를 모든 답을 아는 퀘스트 제공자로 취급
- 확정 대사 사이를 새 복선 대사로 채우기

새 문장이 불가피하면 원문과 구별되도록 검토 기록에 남기고, 인물의 기존 말투와 정보 범위를 넘지 않게 한다.
