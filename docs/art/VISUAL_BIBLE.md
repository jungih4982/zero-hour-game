# ZERO HOUR Visual Bible v1

## Art direction
**Clinical Noir** — Korean webtoon restraint + visual-novel readability + cinematic medical thriller lighting.

Avoid:
- generic glossy AI anime look
- oversized eyes
- random costume drift
- extreme fanservice
- gore as the main horror language
- inconsistent hospital architecture

## Palette by dramatic state
- 22:00: cold neutral whites, restrained blue-gray
- 00:00: near-black + emergency green/red
- B1: industrial tungsten
- B2: sterile cyan/green medical light
- B3: desaturated, almost colorless
- LOOP 0: first meaningful warm natural light

## Character rendering rules
- semi-realistic proportions
- readable silhouette
- realistic fabric/material response
- expressive eyes without anime exaggeration
- skin texture lightly stylized, not plastic
- consistent hairline, eye shape, nose, mole/scar/accessory positions

## Camera language
- normal dialogue: 35–50mm equivalent
- discomfort: off-center framing, negative space
- threat: compressed perspective / longer lens feel
- contamination: repeat a known composition with subtle impossible differences
- extreme close-up only for major narrative punctuation

## Character master package
For every core NPC lock these before production:
1. front portrait
2. 3/4 portrait
3. profile
4. full body front
5. full body 3/4
6. neutral expression
7. fear
8. anger
9. guilt/sadness
10. one signature prop/gesture

Store a written identity spec beside the images.

## Environment rules
The hospital must feel like one real building.

For each location define:
- room dimensions
- door/window positions
- permanent props
- wall/floor/ceiling materials
- signage system
- light sources
- approved camera anchors
- 22:00 state
- blackout state
- post-incident state

## UI
UI must initially feel like stylish game UI but later reveal itself as MNEMOSYNE monitoring software.

Design principles:
- medical instrumentation precision
- restrained typography
- no fantasy ornament
- memory/loop elements use consistent symbols
- Foreknowledge choice must be instantly distinguishable

## Asset naming
`ZH_[TYPE]_[LOCATION/CHARACTER]_[STATE]_[VARIANT]_v###`

Examples:
- `ZH_BG_LOBBY_2200_WIDE_v001.png`
- `ZH_CH_YUJIN_NEUTRAL_HALF_v003.png`
- `ZH_CG_SEA_AGAIN_v002.png`
