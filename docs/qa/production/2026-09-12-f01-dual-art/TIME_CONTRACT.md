# F01 시간 계약 — 구현과 경로 장부

기준 HEAD는 실제 확인된 `f67c6324fdc569857a8bc4e08f07ec3476446ce3`다. 사용자가 비교용으로 제공한 `2f6e21a8...`로 checkout하지 않았다. 시작 시 staged/unstaged 비어 있고 루트 지시문 TXT만 untracked였다. 이전 F04와 민서 v03은 이 HEAD에 들어 있으며 기준 해시와 대조했다. 이번 Git 쓰기 작업은 하지 않는다.

## 수정 전 실제 반례

`EVIDENCE/time-ledger-before.json`은 수정 전 실제 콘텐츠/효과/조건/조사 제한으로 새 게임부터 탐색한 결과다. 원래 상대 대기 구현에서는 CH2가 22시대에 끝난다. **자정만 offset157로 바꾸는 가정**을 분리하여 같은 경로를 실행했을 때 CH2 `offset206=00:49` → `BEGIN_CHAPTER_3` → `offset184=00:27`, 22분 역행을 재현했다. 실제 Android 구버전 저장 진행에서는 CH2 22:46 → CH3 00:27의 숨은 전진 덮어쓰기를 관찰했다. 가정 반례와 GUI 관찰을 혼동하지 않는다.

원인: `STAY_UNTIL_BLACKOUT` +9, `WAIT_FOR_KNOWN_BLACKOUT` +5는 자정을 보장하지 않았고, CH3 시작 `onEnter:setTime184`는 늦게 도착한 경로도 되돌렸다. 정전 이후 상대 비용을 그대로 두면 최대 조사 경로가 00:27을 넘었다. `blackoutMemory.payoff`의 70~120 구간도 자정157과 맞지 않았다.

| 기억의 도착 이득 | Loop2 직접42분, 문자 예측/확인45분. 첫 밤보다 각각8~10분/5~7분 빠름 |

새 `waitUntil`은 현재보다 미래인 경우에만 경과 시간을 소비한다. 시각을 덮어쓰지 않는다. 사건은 시간 증가가 경계를 통과할 때 한 번 기록되고, 큰 행동이 경계를 넘더라도 사건 기록 시각은 고정점이다. 저장 복원·0분 행동·경계 재진입으로 사건 기록이 중복되지 않는다. 실제 사망은 해당 이야기 장면의 효과로만 발생한다.

## 자동 경로 결과

`scripts/test-time-contract.ts` / `scripts/lib/timeContractPaths.ts`: 실제 조건·효과·조사 할당을 사용. 무료 추론을 자동 연결한 경로 탐색이며 GUI가 아니다. 동등한 상태는 합치되 직접/문자, 세 공개 방식, 카트/태준 분기를 각각 유지한다.

- 10,592 도달 상태, 1,920 동등 CH2 종료 상태, 12 분기 집단.
- 직접/문자 × 세 공개 방식 모두 태준 경로 CH2 **00:20~00:27**, 카트 경로 **00:21~00:26**. 카트는 단서를 얻는2분이 필수여서 미조사 최단 태준 경로와 단순 비교하면1분 늦다. 같은 조사 상태에서는 카트 탈출이1분 빠르다.
- 모든 합법 최대 조사 경로 ≤00:27. CH3 시작은00:27. 리셋 외 역행0.
- 00:49 구버전 늦은 상태는00:49를 유지. 정상 새 게임 통과로 계산하지 않음.
- 자동 장면 수/독서 시간 추정은 실플레이나 신규 플레이어 몰입 완료 증거가 아니다.

## 저장 호환성

저장버전5. v4와 이름 마이그레이션 후 v3 저장의 시각·기억·소지품·경로를 그대로 유지하고 `clock.contractVersion=0`을 붙인다. UI는 ‘이전 저장 시각’으로 표시한다. 이미 정전을 지난 기록은 `legacy`로 표시하여 새 정확 시각인 것처럼 소급 기록하지 않는다. 다음 정상 리셋 또는 새 게임부터 계약1을 시작한다. 재개 대사 beat와 설정은 별도 기존 저장을 그대로 사용한다.

원본 SQLite와 이전 증거는 보존했다. 실제 구버전 저장 및 새 게임의 GUI 결과/정확한 재개점은 `BATCH_REPORT.md`, `NEXT_BATCH.md`에서 분리 기록한다.

## 남은 원문 시간 표현 — 편집 미적용

시계 경계와 합법 도달성의 해결을 모든 서사 시간 표현의 해결로 확대하지 않는다. 이동 약50분과 자정 고정 때문에 첫 밤 최대 조사 뒤55분, Loop2에는 더 긴 대기가 남는다. 화면에서 비용을 숨기지 않고 표시했지만, 이 대기를 체험상 풍부하게 만드는 콘텐츠는 아직 없다.

특히 `SCENE_LOOP2_RETURN_302`의 “몇 분 사이에 빈 병실처럼 바뀌어 있었다.”는 이전 302 관찰이 자정보다 훨씬 전인 새 시간 장부와 대조가 필요하다. 이를 주인공이 떠난 뒤 경과 시간으로 읽으면 충돌한다. 짧은 정리 작업의 소요에 대한 표현인지도 원문만으로 확정할 수 없다. 본문을 고치거나 관찰 시각을 몰래 늦추지 않았다. 이 문장의 해석/편집 비교는 `CREATIVE_DECISIONS.md`에 분리한다.
