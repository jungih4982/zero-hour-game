# 이번 실행의 GUI 분류와 증거

단일 GUI 담당자가 Computer Use `@oai/sky`의 화면 캡처와 정상 click/scroll로 플레이했다. `computer-use-inputs.ndjson`은 터치 좌표·횟수·시각·캡처명을 기록한다. 추가 조회/스크롤 캡처는 번호순 JPG에 있다. 빠른 다중 탭은 대사를 넘기는 기능 검수이며 전체 독해 플레이가 아니다. 일부 스크롤은 과하게 이동했고 선택을 수정했다. 잘못 고른 추론은 확정하지 않았고 최종 올바른 단서 조합과 상태를 확인했다.

## A. 수정 전 기존 저장의 정상 입력

원본72/beat32를 바이트 보존 복원 → KEEP_MINSEO_WARNING_PRIVATE → 옛 지도 구조/벽 조사 → 현장 기록에서 CCTV/지도 추론 → CH2 종료83=22:46 → CH3 진입184=00:27 → 태준 밴드 확인 → CH3 세 증언의 민서 beat14.

날짜 지점은 대화 영역에 가려져 중심 터치 후 상태가 바뀌지 않았다. `before-oldmap-date-covered`는78,구조/벽만 조사. `before-ch3-entry`는 이름과 달리 CH2 종료83인 저장이며 다음 화면에서184로 전진 덮어쓰기를 관찰했다. `before-ch3-minseo`는187/beat14다.

00:49→00:27은 실제 수정 전 코드에 **자정만 고치는 가정**을 적용한 자동 반례다. 이 시각을 GUI로 플레이했다고 주장하지 않는다.

## C. 새 게임 주 경로 — 중간 복원 없음

UI 처음부터 시작(확인 포함)으로 게임 상태를 새로 만들었다. 사용자 설정의 standard/이미 본 기본 안내는 유지되어 신규 설치 온보딩 검사가 아니다.

첫 밤: 문자 순서 보존 →52분 도착 →302조사3개 →손목밴드를 놓고 답신 →직원문 →55분 기다려00:00 →첫 죽음 →불빛/시계/잠금 기억 재구성 →리셋.

Loop2: 문자 예측34분 →문자 확인 후 이동9분 →도착45 →첫 전화/자기 전화 →현장 기록에서 정전 경로와 두 전화 추론 →정확한 예지 공개 →직원문65 →92분 대기/자정 개입 →B1.

B1 주 경로에서 카트 중심을 눌렀으나 획득되지 않았다. 다음 문 조사가 실제 선택 기회를 소비했고 린넨실을 조사했다. **`fresh-b1-cart-and-linen`은 오명명이며 실제 문+린넨실 저장**이다. 카트를 얻었다는 증거로 쓰지 않는다. `b1-first-attempt-note.txt`에 정정 기록. 세아 질문 즈음 사용자 포커스 개입 경고가 있어 화면을 다시 확인하고 해당 격리 창을 활성화했다. 정상 상태에서 태준 대면/동행을 계속했다.

이후302 재방문→두 전화/두 번째 전화 보관→CCTV 추궁→06출처 질문→벽 정보 전달→옛 지도날짜/구조/벽3개→현장 기록에서 숨은 통로 추론→태준 지도→서윤 전송→독립조사 수락. 최대 조사/높은 비용 조합으로 CH2종료184,CH3진입184.

집중 독해로 실제 확인한 부분: 도착과 정전 대기, 기억 개입 결과, 재방문 ‘몇 분 사이’와118분 간격, 세 증언의 다른 시점, 민서의 질문/얼굴,00:36휴대전화와 손목시계 차이,01:06밀폐 및 계단 정보. 모든 문장의 감정선/30~45분 체험 평가는 아니다.
