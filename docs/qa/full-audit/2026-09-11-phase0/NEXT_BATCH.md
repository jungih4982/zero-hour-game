# 다음 실행 가능한 첫 안전 배치 — 아직 적용하지 않음
현재 단계는 PHASE 0이다. 이 파일은 리뷰 가능한 후속 작업 범위이며 이번 실행에서 게임 수정을 시작하지 않았다.

## 권장 배치 A: 사건 시각과 기억 피드백의 사실성
대상 이슈: F01, F04. 먼저 재현 회귀 검사를 추가하고, 승인 원문을 바꾸지 않는 엔진/표시 수정만 한다.

1. `SCENE_ACT3_BLACKOUT` 및 `SCENE_LOOP2_BLACKOUT_INTERVENTION`의 자정 진입을 게임 시간 157(21:23→00:00)에 맞춘다. 단순 상단 라벨만 00:00으로 바꾸지 않는다. 이동/대기 효과와 사망 기록도 함께 맞춘다.
2. 50분 초과 이동 대사와 도착 시각의 관계를 검사한다. 출발/도착 기준 및 자정까지 남는 시간이 어긋나면 확정 대사를 수정하지 말고 시간 계약을 비교안으로 제시한다. 기억 payoff의 usableFrom/Until(현재 70–120) 등 연결된 시간 범위도 함께 검사한다.
3. 실제 플레이하지 않은 대체 선택을 Foreknowledge의 “이전에 확인한 결말”로 표시하지 않는다. 플레이 이력에서 확인 가능한 사실을 사용하고, 해당 이력이 없으면 잘못된 과거 설명을 생략한다. F04의 새 게임→유진 공개 첫 진입이 회귀 사례다.
4. 자동 검증: 첫 밤 조사 2개/3개, 두 문자 분기, Loop 2 조기 도착 두 경로, 유진 공개/최소 공개, 모든 정전→사망 기록, 시간 역행 금지, 아직 경험하지 않은 결말 표시 금지.
5. GUI: 동일 Android 화면에서 새 격리 세이브로 첫 정전, 사망, 리셋, 공개 역효과를 다시 플레이하고 이 감사 캡처와 비교한다.

보호 대상: CANON, 확정 대사 원문, 캐릭터 얼굴/의상 원본, 기존 세이브, 레거시, 설정/의존성.
이 배치는 이후 실행 권한이 주어지면 수행할 수 있는 버그 수정 제안이다. 현재 실행에서는 적용하지 않는다.
중단 지점: 시간 보정이 승인 원문/세계 규칙 변경을 요구하거나 기존 저장 데이터 의미를 바꾸면 변경안을 분리한다. 저장 버전/이전 데이터 변환을 무검증으로 변경하지 않는다.
